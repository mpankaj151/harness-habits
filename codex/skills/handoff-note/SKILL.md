# Handoff note

Write the note to `HANDOFF.md` in the working directory (or the path the user names), keeping it under 40 lines.

```
# Handoff: <topic>

## Done
- <what is finished, one line each>

## Decisions
- <choice made and the reason>

## Open items
- <what remains, in priority order>

## Files to open first
- <path>: <why>
```
